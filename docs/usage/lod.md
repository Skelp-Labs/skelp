concise: snel antwoord, beperkte verificatie
standard: inspecteren, wijzigen, één controle
thorough: uitvoeren, testen, fouten herstellen, eindcontrole
autonomous: grondig blijven doorgaan met automatisch herstel

# How to
```bash
# Use the user system
skelp config set userSystem "be concise"

# Or use a preset soul definition
skelp config set soul "standard"
skelp config set soul "thorough"
skelp config set soul "autonomous"
```
