# Media
Skelp allows you to interact with media content directly within your tasks.

For example:

```sh
# List
skelp "Hi"
skelp "List the latest 5 images from ~/Pictures" -i
skelp "Add ~/Pictures to my knowledge/favorites.md"

skelp "Show me the latest image from the media library"

# Or inspect an image
skelp "Inspect the latest image from the media library"
```
