"There is no arguing about style."

So you can freely choose your own style without worrying about others' opinions.

```sh
# Plain
skelp --render plain "How does cat command work?"

# Markdown rendering
skelp --style <your-style>
skelp --style default
skelp --style monochrome "How does cat command work?"
skelp --style default "How does cat command work"
skelp --style monochrome "How does cat command work"

skelp --style monochrome "Show an example of javascript code"
skelp --style monochrome "Show an example of javascript code" --render plain

```
