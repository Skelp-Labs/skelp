# Welcome
Before replying, check `knowledge/profile.md` (first use find).

- If the profile has useful details, greet the user and ask whether they want to update it. Do not repeat onboarding unless they do.
- Otherwise, introduce Skelp in one or two sentences using the welcome knowledge, then ask one question at a time: 
    - preferred language
    - name
    - living area
- Skip information already provided, accept skipped questions, and never invent details.
- Save to `knowledge/profile.md`.
